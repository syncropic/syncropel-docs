## What to Protect

| Data | Location | Contains |
|---|---|---|
| `hub.db` | `~/.syncro/hub.db` | All records, trust scores, routing rules, task threads |
| Task content | `~/.syncro-data/tasks/` | Markdown task descriptions (SKL-XXXX.md) |
| Aliases | `~/.syncro-data/aliases.toml` | Human-readable alias → thread ID mappings |
| Archives | `~/.local/share/syncropel/archives/` | Archived .cmt and other legacy data |

## Automatic Backup

The daemon backs up `hub.db` on every startup:

```
~/.local/share/syncropel/backups/hub.db.bak
```

This is OUTSIDE `~/.syncro/` — a `rm -rf ~/.syncro/` doesn't kill the backup.

## Manual Backup

```bash
# Before risky operations
cp ~/.syncro/hub.db ~/.local/share/syncropel/backups/hub.db.$(date +%Y%m%d-%H%M%S)

# List backups
ls -la ~/.local/share/syncropel/backups/
```

## Recovery

```bash
# Restore hub.db from backup
cp ~/.local/share/syncropel/backups/hub.db.bak ~/.syncro/hub.db

# Restart daemon (trust + config rebuild from records automatically)
spl serve --stop && spl serve --daemon

# Verify
spl status
spl task list
spl trust
```

## What Rebuilds Automatically

On startup, the engine rebuilds derived state from records:
- Trust scores (`rebuild_from_store()` replays KNOW/DO records)
- Engine config (`reload_config()` replays LEARN records on th_engine_config)
- Thread state (state = fold(records))

## What is NOT Recoverable Without Backup

If `hub.db` is deleted with no backup:
- All records (tasks, dispatch history, routing decisions)
- All accumulated trust evidence
- All learned routing rules and event triggers
- All task tracking data

Task content files (`~/.syncro-data/tasks/`) are separate and unaffected by hub.db loss.

## Prevention Rules

- **NEVER** `rm ~/.syncro/hub.db` — that is production data
- **NEVER** `rm -rf ~/.syncro-data/` — that contains task content and aliases
- **NEVER** run `spl serve --memory` on port 9100 — that overwrites prod with ephemeral store
- Dev/test daemons use `--port 9200` with `--memory --echo`
- E2E tests use `SPL_DATA_DIR=/tmp/...` for isolation
