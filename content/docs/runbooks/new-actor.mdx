## The 4-Layer Actor Stack

Every actor needs 4 things configured:

1. **Registration** — who they are (DID, display name, category)
2. **Adapter** — how to reach them (CLI binary, proxy endpoint)
3. **Triggers** — when to wake them (event patterns, schedules)
4. **Review policy** — who reviews their work

## Example: Add a Reviewer Actor

### 1. Register

```bash
spl actor register did:sync:agent:reviewer --display-name Reviewer --category agent
```

### 2. Bind Adapter

```bash
spl adapter add did:sync:agent:reviewer \
  --family cli \
  --binary claude \
  --timeout 300 \
  --max-concurrent 1
```

### 3. Create Triggers

```bash
# Wake reviewer when dev claims done
spl config add-trigger \
  --name "reviewer-on-completion" \
  --match "act=KNOW,body.topic=task_completion" \
  --target did:sync:agent:reviewer \
  --goal "A task was completed. Run spl task list --status review. Read the task content and the code changes. Approve or reject." \
  --budget 1.0 \
  --timeout 300 \
  --cooldown 60
```

### 4. Verify

```bash
spl actor show reviewer
spl adapter list
spl config list-triggers
```

## Example: Add a CI Bot

```bash
# Register
spl actor register did:sync:agent:ci --display-name "CI Bot"

# Webhook adapter (calls external CI)
spl adapter add did:sync:agent:ci \
  --family proxy \
  --provider webhook \
  --base-url https://ci.example.com/trigger

# Trigger on merge (task approval)
spl config add-trigger \
  --name "ci-on-approval" \
  --match "act=KNOW,body.topic=task_verdict,body.verdict=accept" \
  --target did:sync:agent:ci \
  --goal "Run full test suite" \
  --budget 0.00 \
  --timeout 600
```

## Team Evolution

Start with 2 actors (human + dev). Add more as evidence demands:

| Phase | Actors | When to Add |
|---|---|---|
| Pair (0-50 tasks) | human + dev | Start here |
| Triangle (50-150) | + director | Human repeating decompositions >60% of time |
| Square (150-400) | + reviewer | 3+ quality escapes in last 50 tasks |
| Team (400+) | + dev-2 | Primary executor at capacity >50% of time |

See the [team evolution spec](https://github.com/syncropic/syncropel-spec/blob/main/04-actors/10-team-evolution.md) for measured transition triggers.
