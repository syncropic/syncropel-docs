---
title: Summarize a research paper with 3 AI models
description: Three AI models each summarise a paper, and Syncropel picks the answer most of them agree on. Shown for the command line, the TypeScript SDK and the Python SDK.
---

## Problem

You want a reliable one-paragraph summary of a research paper, plus a 1-5 rating of methodology quality. One AI model is good but sometimes invents details or leans too much on the abstract. You'd rather ask three and take the answer most of them agree on.

## Recipe

One query, three AI models, combined with `consensus` (take the answer most agree on). `min_quorum: 2` means the query doesn't wait for a slow third model.

### With the command line

```bash
spl infer "Summarise this paper in one paragraph and rate methodology 1-5: <paste abstract + methods>" \
  --kind core.summary.v1 \
  --responder llm:sonnet \
  --responder llm:gpt-4o \
  --responder llm:gemini-1.5 \
  --fold consensus \
  --min-quorum 2 \
  --top-k 3 \
  --budget 0.30 \
  --timeout 60 \
  --wait
```

Example output:

```text

  {
    "summary": "The authors propose a transformer-based approach to...",

```

### With the TypeScript SDK

```typescript
import { Client } from "@syncropel/sdk";

const client = new Client({ baseUrl: "http://localhost:9100" });

const result = await client.infer({
  input: {
    goal: "Summarise this paper in one paragraph and rate methodology 1-5",
    context: { abstract: "...", methods: "..." }
  },
  responders: [
    { kind: "llm", model: "~sonnet" },
    { kind: "llm", model: "~gpt-4o" },
    { kind: "llm", model: "~gemini-1.5" }
  ],
  fold: { function: "consensus", min_quorum: 2 },
  answer_shape: {
    kind: "core.summary.v1",
    required_fields: ["body.summary", "body.rating"]
  },
  relevance: { top_k: 3 },
  side_effects: { max_cost_usd: 0.30, max_latency_secs: 60 }
});

console.log(result.answer);
console.log(`Trust: ${result.trust_summary.mean.toFixed(2)}`);
console.log(`Cost: $${result.cost_actual_usd.toFixed(4)}`);
```

### With the Python SDK

```python
from syncropel import Client

client = Client(base_url="http://localhost:9100")

result = await client.infer({
    "input": {
        "goal": "Summarise this paper in one paragraph and rate methodology 1-5",
        "context": {"abstract": "...", "methods": "..."}
    },
    "responders": [
        {"kind": "llm", "model": "~sonnet"},
        {"kind": "llm", "model": "~gpt-4o"},
        {"kind": "llm", "model": "~gemini-1.5"},
    ],
    "fold": {"function": "consensus", "min_quorum": 2},
    "answer_shape": {
        "kind": "core.summary.v1",
        "required_fields": ["body.summary", "body.rating"],
    },
    "relevance": {"top_k": 3},
    "side_effects": {"max_cost_usd": 0.30, "max_latency_secs": 60},
})

print(result.answer)
print(f"Trust: {result.trust_summary['mean']:.2f}")
print(f"Cost: ${result.cost_actual_usd:.4f}")
```

## How the answer is chosen

Answers that are exactly the same are grouped together. Each group's weight is the total trust of the models that gave it (each counts for at least 0.05). The group with the highest weight wins.

Only identical answers count as agreeing. If the three summaries are worded differently but give the same rating, they do not group together. For long text answers, `ensemble_weighted` with a similarity-based weight usually works better. Or ask the models for a single rating and let them agree on that alone.

## The trade-off

Asking three models (about 5 to 15 seconds each) costs three times as much as asking one. You are paying for more reliable answers. If one model's summary is good enough, use `single_shot` with one model, and keep this for cases where you have seen the models disagree.

`min_quorum: 2` stops one slow model from holding everything up. If you raise it to 3, one timeout ends the query, and you get `quorum_not_met` instead of an answer.

## Try it on a test workspace

With three LLM providers configured in `~/.syncro/providers.yaml`, the command above runs as written. If you only have one provider, point the other two at the same provider with different model names.
