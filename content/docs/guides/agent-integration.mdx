## The Proxy Path (Universal)

Any AI agent that makes LLM API calls can use Syncropel. Change one line:

```python
# Anthropic
client = anthropic.Client(base_url="http://localhost:9100")

# OpenAI
client = OpenAI(base_url="http://localhost:9100/v1")

# Any HTTP client
# POST http://localhost:9100/v1/messages
```

The proxy records every call — including tool calls within the conversation. No hooks, no tracer, no configuration beyond the base_url.

## Agent Onboarding Prompt

Copy this into any AI agent to set up Syncropel:

```text
Install and configure Syncropel — an LLM API proxy that records every call.

1. Check Python: python3 --version (need 3.12+)
2. Install: curl -sSf https://get.syncropic.com/spl | sh
3. Add to PATH: export PATH="$HOME/.local/bin:$PATH"
4. Verify: spl --version
5. Initialize: spl init --yes
6. Start: spl serve &
7. Wait 5s, verify: curl -s http://localhost:9100/health

Proxy is ready. Set base_url="http://localhost:9100" in your SDK.
Dashboard: http://localhost:9100/console
Troubleshooting: https://docs.syncropel.com/docs/reference/troubleshooting
```

### With API key

```text
Install Syncropel with API key for real proxy usage:

1. curl -sSf https://get.syncropic.com/spl | sh
2. export PATH="$HOME/.local/bin:$PATH"
3. spl init --key YOUR_ANTHROPIC_KEY --yes
4. spl serve &
5. curl -s http://localhost:9100/health

Set base_url="http://localhost:9100" in your code. Every call recorded at localhost:9100/console.
```

## Skill File (Claude Code)

Install a skill file that teaches Claude Code about spl commands:

```bash
spl setup --claude
```

This installs `~/.claude/skills/syncropel/SKILL.md` — a thin pointer that directs Claude Code to use `spl help-agent` for command discovery.

## Progressive Discovery

AI agents discover spl capabilities through token-budgeted help:

| Tier | Command | Tokens | What It Returns |
|------|---------|--------|-----------------|
| 0 | `spl help-agent -j` | ~200 | All command groups and flags |
| 1 | `spl help-agent <group> -j` | ~400 | Subcommands and usage for a group |
| 2 | `spl help-agent --conventions -j` | ~500 | Governance model reference |

Total: ~1,100 tokens for full CLI knowledge (vs ~20,000 tokens for full docs).

## Project Discovery

```bash
spl init --project
```

Creates `.syncro/ABOUT.md` and `.syncro/CONVENTIONS.md` in your project root. When an AI agent opens the project, it finds these files and knows spl is available.

## JSON Output

Every spl command supports `-j` / `--json`:

```bash
spl namespace ls -j
# {"status":"ok","data":[{"id":"default","level":"DEFAULT"}]}
```

Exit codes for programmatic detection:

| Code | Meaning |
|------|---------|
| 0 | Success |
| 1 | Generic error |
| 3 | Not found |
| 4 | Validation failure |
| 5 | Registry not reachable |
| 6 | Auth failure |
