## Overview

The console shows every LLM call flowing through your proxy in real-time. Open [localhost:9100/console](http://localhost:9100/console).

## What you see

Each API call appears as a record with:
- **Actor** — who made the call (your app, an agent, a script)
- **Content** — the prompt or response (truncated)
- **Metadata** — model, tokens, cost, latency (shown below the record)

```
proxy-client › What is the capital of France?
  sonnet-4-6 · 3 msg · stream

The capital of France is Paris...
  sonnet-4-6 · 142→38 tok · $0.001 · 1.2s
```

## Live Feed

Records stream in chronological order. New calls appear at the bottom. The feed polls every 2 seconds.

## Cost Dashboard

Below the feed, a mini dashboard shows aggregate stats updated every 10 seconds:

- **Total cost** — running USD total across all calls
- **Call count** — how many API calls through the proxy
- **Models used** — which models and how often
- **Records** — total records in the database
- **Threads** — groups of related calls

## Filters

Click any item in the dashboard to filter the feed. Click again to unfilter. Controls:
- **All**: show everything (reset filters)
- **Inv**: invert current selection
- **sys**: toggle system records on/off

## Saved Views

Save your current filter state as a named view. Views persist in your browser across sessions.

## Threads

The sidebar shows active threads with search. Click a thread to see its full record timeline.

## Record Types

Each record has a type indicator:

| Symbol | Type | Meaning |
|--------|------|---------|
| ○ | Intent | A goal or plan was stated |
| ◑ | Action | Work was performed |
| ◕ | Knowledge | A fact was recorded |
| ● | Learning | An insight or result was captured |

Most proxy records are Intent (your prompt) and Learning (the response).
