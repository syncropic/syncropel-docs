## What is spl serve?

`spl serve` starts a local server on port 9100 that:

1. **Proxies LLM calls** — Anthropic and OpenAI compatible endpoints
2. **Records everything** — every call stored in a local DuckDB database
3. **Opens the workspace** — `spl serve --open` launches [syncropel.com/local](https://syncropel.com/local) which connects to your daemon
4. **Computes trust** — reliability scores from your usage history
5. **Runs offline** — no internet required after install

## Storage

All data is stored locally at `~/.syncro/hub.db` (DuckDB). The database is persistent — records survive restarts.

## API

The registry exposes 160+ HTTP endpoints matching the production API. Key endpoints:

| Endpoint | Method | What |
|----------|--------|------|
| `/v1/messages` | POST | Anthropic API proxy |
| `/v1/chat/completions` | POST | OpenAI API proxy |
| `/v1/records` | GET | Query stored records |
| `/health` | GET | Server status + proxy stats |
| `/console` | GET | Redirects to syncropel.com/local |

## Configuration

| Setting | Default | How to change |
|---------|---------|---------------|
| Port | 9100 | `spl serve --port N` |
| Database | `~/.syncro/hub.db` | Config file |
| Auth | Bearer token (auto-generated) | `~/.syncro/secrets/daemon_token` |

## Starting and Stopping

```bash
spl serve          # Start in foreground
spl serve &        # Start in background
spl serve --stop   # Stop the daemon
spl serve --status # Check if running
```

## Backup and Reset

```bash
# Backup (stop server first)
cp ~/.syncro/hub.db ~/.syncro/hub.db.backup

# Reset (delete database to start fresh)
rm ~/.syncro/hub.db
spl serve  # Creates a new empty database
```

## File Layout

```
~/.syncro/                    # All Syncropel data (SPL_HOME)
  config.toml                 # Configuration
  hub.db                      # DuckDB database
  secrets/
    daemon_token              # Auth token for registry API
    anthropic_key             # Encrypted API key
  keys/
    default.pem               # Ed25519 signing key
  sessions/                   # Session history
  logs/                       # Structured logs

.syncro/                      # Per-project (committed to repo)
  ABOUT.md                    # Project discovery file
  CONVENTIONS.md              # Governance reference
```

## Syncing with the Hub

Your local registry can sync with api.syncropel.com:

```bash
spl auth login       # Authenticate
spl sync push        # Push records to hub
spl sync pull        # Pull from hub
```

Only metadata is synced — your actual prompts and responses stay local. See the [Sync Guide](/docs/guides/sync).
