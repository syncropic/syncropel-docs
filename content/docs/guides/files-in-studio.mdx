## Overview

In the Studio, a file always arrives in a conversation: someone attaches it to a
message. **files** is the place that gathers them, so you can find a file
without remembering where it was sent. The files on disk that `spl fs` manages
are a separate thing; see [Filesystem](/docs/guides/filesystem) for those.

## Attach a file

In a conversation, press the paperclip on the composer and choose the file. It
lands in that conversation, and it appears in **files**.

Only the people who can open that conversation can open the file. Attaching a
file never shares it with anyone new.

## Find a file

Open **files** from the side of the Studio. The newest files come first, grouped
under **today**, **yesterday** or how many days ago they arrived. Each row shows:

- the file's title;
- **a copy** or **live**. An attached file is **a copy**: it stays exactly as it
  was when it was sent. A **live** item is worked out again from where it came
  from whenever that changes;
- what kind of file it is and the conversation it came in;
- who attached it, and how many people can open it, as "can open it" after a
  count.

To narrow the list, use the same narrowing bar as every other list: choose a kind
of file, type a word, or both. A kind with nothing in it shows its count as 0 so
you can tell the file you're looking for isn't there.

Before you pick one, the side of the page shows how many files there are, as
**things anyone attached**. With none yet, it reads: "Nothing has been attached
yet. Attach a file from a conversation, with the paperclip on the composer, and
it lands in that conversation and appears here."

## Open a file

Pick a row to open it. Beside it, **where this is argued about** shows the
conversation the file came in, starting where it arrived, and says how many later
messages cite it. Press the conversation's name to go there.

## Common gotchas

- **A file you can't see.** If you can't open the conversation a file came in,
  the file isn't listed for you.
- **Changing a file.** An attached file is a copy. To change it, attach the new
  version in the conversation.
