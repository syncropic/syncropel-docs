`spl run` starts a run as you and stays with it: every turn prints as it
happens, a question the run needs answered is put to you in place, and the
outcome prints when the run ends, with the diff if it changed a repository.

```bash
spl run "Record one note saying the walkthrough works, then stop."
```

The full guide is [Running work with spl run](/docs/guides/spl-run). It covers:

- what a run is and which member carries it out,
- what each streamed line means,
- what happens when a run parks on a decision, and how you answer it,
- the outcome and its exit codes,
- how a run is bounded (turns, budget, time, the declared tools),
- giving a run a declared repository, and the green check it then owes,
- what does and does not stop a run.

## The old goal path

`--legacy` runs the pre-v0.217 path: the goal is filed as an intent, routed to
a member, and polled until something closes it. It exists only for callers
that depend on that shape. Prefer the seat.
