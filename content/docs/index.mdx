## What Syncropel is

Syncropel gives you a **workspace**: your own place, at your own address, where you, the people you invite and your AI assistants work together. Conversations, tasks, files and decisions stay in one place, and you can see what was done and why.

```
                    alice.syncropel.app  (your workspace)
   ┌───────────────────────────────────────────────────────────┐
   │   conversations · tasks · files · decisions · assistant    │
   └───────────▲───────────────────▲───────────────────▲───────┘
               │                   │                   │
          you, in the         people you          your assistant
          Studio (browser)    invite
```

## For developers

Syncropel also runs on your own computer, and everything in a workspace can be reached from code.

```bash
# Linux + macOS
curl -sSf https://get.syncropic.com/spl | sh

# Windows (PowerShell)
irm https://get.syncropic.com/spl.ps1 | iex

# Then
spl init && spl serve
```

Follow the [Quickstart](/docs/start) for a five-minute walkthrough, or jump to the [TypeScript SDK](/docs/guides/typescript-sdk) or [Python SDK](/docs/guides/python-sdk). A hosted workspace works from the command line too: [Connect the command line](/docs/get-started/connect-the-command-line).

### What a Syncropel thread looks like

Every coordination event (chat, task, code change, tool call, observation, intent) becomes a record. Records group into threads. Threads produce trust:

```text
fix-checkout-timeout              5 records · 3 actors

● you      INTEND  "Fix checkout timeout before launch"                14m ago
○ agent    DO      Profiled API: connection pool saturated at 10     12m ago
○ agent    DO      Patch applied: pool 10 → 50, deployed to staging    9m ago
○ monitor  KNOW    p99 latency 4.2s → 180ms: 340 users unblocked      6m ago
○ agent    LEARN   "Pool sizing must scale with replicas"              now
                   captured · next similar issue replays the solution
```

`●` is human; `○` is an AI agent or system. Every record is content-addressed and signed by its actor. The `LEARN` at the end is captured as a reusable pattern: next time the same shape of issue appears, the workspace can reuse what worked.

That same thread can be queried via the [TypeScript SDK](/docs/guides/typescript-sdk), [Python SDK](/docs/guides/python-sdk), or [MCP-compatible AI clients](/docs/integrate/ai-clients) (Claude Desktop, Cursor, Cline, Zed, OpenCode, and others). Hosted workspaces ship with **[the chief of staff](/docs/get-started/the-assistant)**, a default conversational assistant that responds in any thread you open by typing, so you do not have to wire anything up.
