## What is Syncropel?

Syncropel is a coordination protocol for hybrid human-AI teams. Every intent, every action, every insight — one protocol. The fundamental unit is an 8-field immutable, content-addressed record.

```bash
curl -sSf https://get.syncropic.com/spl | sh
spl init
spl serve --daemon
```

## Core Concepts

| Concept | What It Is |
|---|---|
| **The Record** | 8 fields, 7 hashed. `id = SHA-256(canonical_json(7 fields))`. Immutable, content-addressed. |
| **Act Types** | 8: GET, PUT, CALL, MAP (effects) + INTEND, DO, KNOW, LEARN (coordination) |
| **Trust** | 3D: `trust(actor, domain, judged_by)`. Wilson LB. 90-day decay. |
| **The Dial** | d ∈ [0,1]. REPLAY ($0.00) → ADAPT → EXPLORE → CREATE ($0.50+) |
| **Threading** | INTEND opens, KNOW with fulfills closes. Fork/merge like Git. |
| **Patterns** | Hash chains of successful threads. Match cascade: L1→L2→L3→CREATE. |
| **Actors** | DID-based identity. Three layers: DID (immutable) / Substrate (mutable) / Instance (ephemeral). |
| **Engine** | 4 loops: INGEST (<100μs), RECONCILE, TICK, CRON. Everything else is data. |

## Architecture

```
spl (Rust CLI + server binary, ~11MB)
├── spl serve (HTTP API + engine + LLM proxy, port 9100)
├── spl task (hypothesis-driven task management, 19 commands)
├── spl dispatch (multi-actor coordination with worktrees)
├── spl trust (3D trust with Wilson LB)
└── spl memory (cross-session actor learning)
```

The spec lives at [syncropel-spec](https://github.com/syncropic/syncropel-spec). The implementation at [syncropel-core](https://github.com/syncropic/syncropel-core).
