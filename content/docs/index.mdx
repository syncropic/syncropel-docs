## What is Syncropel?

Syncropel sits between your code and your LLM. Change one line — your `base_url` — and get full observability on every API call: model, tokens, cost, and latency, all recorded automatically.

```bash
curl -sSf https://get.syncropic.com/spl | sh
spl init
spl serve
```

Then point your SDK to `http://localhost:9100`. Every call is now recorded.

## The Protocol

Syncropel is **verification infrastructure for AI computation** — a formal algebra and governance protocol that any AI system can embed to become trustworthy. Like TLS for the web, Syncropel is invisible infrastructure: your agents run, Syncropel verifies.

The protocol is built on immutable foundations: **effect primitives** (GET, PUT, CALL, MAP), **data shapes** (VOID, ONE, OPTIONAL, MANY, KEYED), **hash levels** (Exact, Structural, Flow, Intent), and a **deterministic governance pipeline** — all enforced by mathematics, not promises.
