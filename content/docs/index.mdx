## What is Syncropel?

Syncropel is a coordination protocol that makes human-AI collaboration auditable, trustworthy, and self-improving. Every action is an immutable record. Trust is earned from evidence. Proven workflows replay automatically at zero cost.

```bash
curl -sSf https://get.syncropic.com/spl | sh
spl init
spl serve --daemon
```

## How It Works

**Records** are the fundamental unit — 8 fields, content-addressed with SHA-256. Every intent, action, observation, and insight is a record. Records are immutable and self-verifying.

**Threads** group related records into workflows. A thread starts with an intent and ends with a fulfillment. Threads fork and merge like Git branches.

**Trust** accumulates from outcomes. When an actor completes work and an evaluator confirms quality, trust grows. Trust is computed with Wilson lower bound — statistically principled, handles small samples correctly.

**The Dial** maps trust to cost. Proven workflows replay at $0.00 (the REPLAY zone). Novel work requires full computation (the CREATE zone). As trust grows, costs converge to zero.

**Patterns** form from repeated successful workflows. When a pattern crystallizes (high trust, 100+ observations, compression gain), future matching work replays the pattern instantly.

## Core Concepts

| Concept | Description |
|---|---|
| **Record** | 8-field immutable unit. `id = SHA-256(canonical_json(7 fields))`. |
| **Thread** | Sequence of records sharing a thread ID. Opens with INTEND, closes with KNOW. |
| **Actor** | Any participant — human or AI. Identified by DID (`did:sync:type:name`). |
| **Trust** | 3-dimensional: `trust(actor, domain, judged_by)`. Evidence-based, not granted. |
| **Dial** | Continuous [0, 1]. Maps trust + pattern match to cost zone. |
| **Pattern** | Crystallized workflow. L1 (exact) through L3 (intent-level) matching. |

## The `spl` CLI

```bash
spl serve --daemon          # Start the server
spl status                  # Check health

spl intend "Deploy v2"      # Record an intent
spl do "Ran tests"          # Record an action
spl know "Tests passed"     # Record an observation
spl learn "Use staging"     # Record an insight

spl task add "Fix auth"     # Create a task
spl task list               # See all tasks
spl task done SKL-001       # Complete a task

spl trust                   # View trust scores
spl memory list             # View actor memories
```
