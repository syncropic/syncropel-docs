## Proxy Integrations (Production)

Works with any SDK or tool that supports custom API base URLs:

| SDK / Tool | How to Connect |
|------------|----------------|
| Anthropic Python | `client = anthropic.Client(base_url="http://localhost:9100")` |
| Anthropic TypeScript | `new Anthropic({ baseURL: "http://localhost:9100" })` |
| OpenAI Python | `client = OpenAI(base_url="http://localhost:9100/v1")` |
| LangChain | Set `ANTHROPIC_BASE_URL=http://localhost:9100` |
| Any HTTP client | `POST http://localhost:9100/v1/messages` |

## Editor Integrations (Preview)

| Editor | Setup | What It Does |
|--------|-------|-------------|
| Claude Code | `spl setup --claude` | Hooks into session events, records tool calls |
| VS Code | `spl setup --skills` | MCP server for extensions |
| Zed | Detected by `spl init` | MCP config |
| Cursor | Detected by `spl init` | MCP config |

## SDK Integrations (Planned)

## Status Definitions

- **Production**: Tested, security-hardened, recommended for use
- **Preview**: Works but may change, use with awareness
- **Planned**: Designed but not yet implemented
