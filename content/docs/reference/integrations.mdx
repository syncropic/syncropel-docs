## Proxy Integrations (Production)

Any SDK or tool that supports custom API base URLs works:

| SDK / Tool | How to Connect |
|------------|----------------|
| Anthropic Python | `anthropic.Client(base_url="http://localhost:9100")` |
| Anthropic TypeScript | `new Anthropic({ baseURL: "http://localhost:9100" })` |
| OpenAI Python | `OpenAI(base_url="http://localhost:9100/v1")` |
| LangChain | `ANTHROPIC_BASE_URL=http://localhost:9100` |
| Any HTTP client | `POST http://localhost:9100/v1/messages` |

The proxy captures everything — prompts, responses, tool calls, model, tokens, cost, and latency.
