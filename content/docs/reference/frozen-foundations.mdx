## Frozen Foundations

Syncropel is built on 15 immutable foundations that will never change. These define the atomic vocabulary of the protocol:

- **4 effect primitives**: GET, PUT, CALL, MAP
- **5 data shapes**: VOID, ONE, OPTIONAL, MANY, KEYED
- **4 dial zones**: REPLAY, ADAPT, EXPLORE, CREATE
- **4 hash levels**: Exact, Structural, Flow, Intent

These are described in the [Effects](/docs/concepts/effects), [Dial](/docs/concepts/the-dial), and [Hash Levels](/docs/concepts/hash-levels) concept pages.

For the complete specification, see the [Syncropel Spec](https://github.com/syncropic/syncropel-spec).
