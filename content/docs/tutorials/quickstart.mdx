## Install

### Linux

```bash
curl -sSf https://get.syncropic.com/spl | sh
```

Installs to `~/.local/bin/spl`.

### Windows (PowerShell)

```powershell
irm https://get.syncropic.com/spl.ps1 | iex
```

Installs to `%LOCALAPPDATA%\Programs\spl\spl.exe`.

### macOS

macOS currently requires building from source. See the [full quickstart](/docs/start#macos-build-from-source) for instructions.

### Verify

```bash
spl version
```

You should see `spl 0.15.0 (Rust kernel)` or whatever the latest is.

## Initialize

Set up your local configuration:

```bash
spl init
```

This creates `~/.syncro/config.toml` with default settings. You only need to do this once.

## Start the server

```bash
spl serve --daemon
```

The Syncropel server runs in the background on port 9100. Check that it's healthy:

```bash
spl status
```

You should see:

```
Syncropel kernel <version>
Status:  ok
```

## Create your first record

Every action in Syncropel is a record. Let's create one:

```bash
spl intend "Set up monitoring for the production API"
```

This creates an INTEND record — a statement of what you want to accomplish. The output shows the thread ID where the record was stored.

## Record what happened

As you work, record your actions and observations:

```bash
spl do "Configured alerting thresholds"
spl know "All endpoints responding under 200ms"
```

Each command creates a new record on the same thread. Together, they tell the story: you intended to set up monitoring, you configured alerts, and you observed the results.

## View your work

```bash
spl thread list
```

This shows all active threads with their latest activity.
