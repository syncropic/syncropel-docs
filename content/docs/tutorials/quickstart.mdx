## Prerequisites

| Requirement | Minimum | Check |
|-------------|---------|-------|
| Python | 3.12+ | `python3 --version` |
| curl | any | `curl --version` |
| OS | Linux (x86_64, arm64), macOS (arm64, x86_64) | `uname -sm` |

**Quick check:**

```bash
python3 -c "import sys; assert sys.version_info >= (3, 12), f'Need 3.12+, got {sys.version}'"
```

If Python is too old: `brew install python@3.12` (macOS) or `sudo apt install python3.12` (Ubuntu).

## Install

```bash
curl -sSf https://get.syncropic.com/spl | sh
```

**Verify:**

```bash
spl --version
```

You should see `syncropel-cli v0.8.x`. If you see "command not found", add `~/.local/bin` to your PATH:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

### What the install script does

The install script:
1. Detects your OS and architecture
2. Installs [uv](https://docs.astral.sh/uv/) (fast Python package manager) if not present
3. Installs `syncropel-cli` and its dependencies via `uv tool install`
4. Verifies the `spl` binary is available

The script does NOT:
- Require sudo or root access
- Modify system Python
- Install anything outside `~/.local/`
- Send telemetry or usage data

Source: [get.syncropic.com/spl](https://get.syncropic.com/spl) (view the script before running)

## Configure

```bash
spl init
```

The wizard creates `~/.syncro/`, detects your editors, and sets up your API key.

**No API key?** Use test mode — a deterministic model that doesn't call any API:

```bash
spl init --key test --yes
```

Test mode is useful for trying Syncropel without spending money. Records are created but responses are predetermined.

**Verify:**

```bash
ls ~/.syncro/config.toml && echo "OK"
```

## Start the registry

```bash
spl serve
```

Your local registry is running at `http://localhost:9100`.

**Verify:**

```bash
curl -s http://localhost:9100/health | python3 -m json.tool
```

You should see `"status": "ok"`. If this fails, see [Troubleshooting](/docs/reference/troubleshooting).

## Point your SDK at the proxy

Change one line in your code:

```python
import anthropic

# Before:
# client = anthropic.Client()

# After:
client = anthropic.Client(base_url="http://localhost:9100")

response = client.messages.create(
    model="claude-sonnet-4-6",
    max_tokens=100,
    messages=[{"role": "user", "content": "Hello!"}]
)
```

Every API call is now recorded with model, tokens, cost, and latency.

Works with any SDK that supports custom base URLs — Anthropic, OpenAI, LangChain, etc.

**Verify** the call was recorded:

```bash
curl -s http://localhost:9100/v1/records?limit=1 | python3 -m json.tool
```

## See the dashboard

Open [http://localhost:9100/console](http://localhost:9100/console) in your browser.

You'll see every LLM call with:
- Model and tokens used
- Cost estimate
- Latency
- Full audit trail

## What's happening

Syncropel sits between your code and the LLM API. Every call flows through the proxy, gets recorded, and becomes part of your trust history.

## Sync Across Devices (Optional)

To access your work from another machine, connect to the hub:

```bash
# Authenticate
spl auth login

# Push your records
spl sync push
```

On your other machine:
```bash
curl -sSf https://get.syncropic.com/spl | sh
spl init --yes
spl auth login
spl serve &
spl sync pull
```

Your identity, trust scores, and record history follow you.

Learn more: [Sync Guide](/docs/guides/sync) | [Auth Guide](/docs/guides/auth)

## Uninstalling

```bash
uv tool uninstall syncropel-cli
rm -rf ~/.syncro/
```

This removes the CLI binary and all local data (database, keys, config).
