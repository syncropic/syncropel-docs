Open a conversation in your workspace and type, and your assistant answers. On a hosted workspace it's there from your very first message. It's called the **chief of staff** ("the chief").

## What the chief does

- **Answers from what's in your workspace.** It reads what you're allowed to read: your conversations, tasks, files and decisions. It answers from those.
- **Asks you when it needs to.** If something needs your decision, it raises a clear question instead of deciding for you.
- **Does jobs, not just answers.** Ask it to "summarize last week's decisions" or "tidy up the tasks tagged beta", and it works through the steps in front of you.

## How a conversation works

```
 you type ──▶ your message is saved in the conversation
                     │
                     ▼
          the chief reads the conversation so far
                     │
                     ▼
     its reply is saved in the same conversation ──▶ you see it
```

Everything stays in the conversation, so it's still there when you come back tomorrow, and the chief picks up where you left off. There's nothing to start or save.

## When a question turns into a job

Some messages need work, not just a reply. When that happens:

- **The work is done as you.** It uses your permissions, so it can never do more than you could yourself, and what it changes is recorded as done on your behalf.
- **Each step shows up in the conversation**, so you can watch it happen.

## How much you can use it

| Plan | Assistant use |
|---|---|
| Free | A starting allowance, once (it doesn't renew) |
| Pro | Included every month. Past what's included, the assistant pauses until more is available (for example, when next month's share begins); nothing is charged on top. |

See [Plans and billing](/docs/get-started/pricing).

## If the chief doesn't answer

- **On Free, the starting allowance may be used up.** Move the workspace to Pro on [account.syncropel.com](https://account.syncropel.com) to keep going.
- **On Pro, this month's share may be used up.** The assistant comes back when more is available.
- **Your workspace may be waking up** after a quiet spell. Wait a few seconds and try again.

## For developers

The chief is defined by a [blueprint](/docs/concepts/blueprints), like any other assistant, so you can read it, change it or replace it. When a message needs real work, the chief does it as a [work loop](/docs/concepts/work-loop). To start one yourself and watch it, use [`spl run`](/docs/guides/running-a-goal). 


### Turning the assistant on when you self-host

A workspace you run yourself starts blank until you choose what runs on it. There are two ways to give it an assistant.

```bash
# At init: seed a ready-to-use setup that installs the chief.
spl init --preset recommended    # presets: recommended | blank

# Or at any time later:
spl blueprint install <path-to-blueprint> --accept-plan <hash>
```

Every preset except `blank` installs the chief. If you initialized bare and the
assistant seems silent, this is why, and nothing is broken: install the chief
with the `spl blueprint install` command above.

A workspace on your own computer has no AI model until you give it a key (`spl config set-key anthropic <your key>`, then restart); until then the chief is installed but silent, and `spl run` says so.

### If the assistant is silent on a workspace you run yourself

If you send a message and nothing comes back, work through this in order:

1. **You initialized bare and never installed the chief.** The most common
   cause on a self-host. Run `spl blueprint install <path-to-blueprint> --accept-plan <hash>`, or
   re-init with `--preset recommended`.
2. **No AI model is set up, or it is rejecting requests.** An expired key
   or a used-up quota means no reply. Run `spl doctor`: it reports
   problems with this.
3. **The message went to a task thread.** The chief answers in conversations. A note added to a task thread gets no reply.
4. **Still stuck?** See [Troubleshooting](/docs/get-started/troubleshooting), or
   run `spl thread records <thread-id>` to check your message was saved.
