This section takes you from "I just heard about Syncropel" to "I have a secure daemon running with a browser paired to it." It is intentionally more detailed than the [Quickstart](/docs/start) — read Quickstart if you want the 10-minute happy path; read this section if something went wrong on your first try, or if you're setting up a machine that will do real work.

## Suggested reading order

**First time, want a hosted instance.** Read [Hosted instance signup](/docs/get-started/hosted) — the syncropel.com flow gets you to a working instance without installing anything. You can also `spl token save <bearer>` to get the CLI talking to the hosted daemon, then jump back to [Pairing](/docs/get-started/pairing) for additional devices.

**First time installing locally.** Start at [Install](/docs/get-started/install), proceed through [First run](/docs/get-started/first-run) and [Starting the daemon](/docs/get-started/daemon), stop at [Service accounts and tokens](/docs/get-started/service-accounts) — that page gets you to a working secure daemon. Everything after is situational.

**Pairing a second device.** Jump to [Pairing](/docs/get-started/pairing).

**Something is broken right now.** [Troubleshooting](/docs/get-started/troubleshooting) first, then [Reset and uninstall](/docs/get-started/reset-uninstall) if you need to start over.

**Exposing to other machines.** [Exposing the daemon securely](/docs/get-started/exposing) covers the three safe paths and the one you should never take.

## What "Syncropel" means on your machine

`spl` is a single binary. Once installed, it is both the CLI (`spl task list`, `spl intend …`) and the server (`spl serve --daemon`). They communicate over a local Unix socket on Linux and macOS, and over TCP on Windows. The server persists everything it knows to `~/.syncro/hub.db`, a SQLite file.

That's the whole system. No Docker required, no separate language runtime, no external database. The pages in this section are about getting that one binary installed correctly and pointing it at a well-formed `~/.syncro/` directory.
