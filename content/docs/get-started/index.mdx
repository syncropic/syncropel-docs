There are two ways in. Most people want the first.

```
           ┌──────────────────────────────────┐
           │   Do you want to install things?  │
           └────────────────┬─────────────────┘
                 no         │         yes
          ┌─────────────────┴──────────────────┐
          ▼                                    ▼
  Use it in your browser               Run it on your own computer
  (we run it for you)                  (developers, self-hosting)
  ─ Create your workspace              ─ Install spl
  ─ Plans and billing                  ─ First run
  ─ Your hosted workspace              ─ Connect the command line
```
