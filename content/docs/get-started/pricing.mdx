## TL;DR

- **Local**: free. Run `spl serve` on your laptop or your own server. No subscription, no usage limits, no telemetry.
- **Hosted**: **$25 per month per instance**, with a **30-day free trial**. Each hosted instance is a fully managed `<label>.syncropel.app` with TLS, edge ingress, and a persistent record store.
- **Managed inference (api.syncropic.com)**: optional, usage-billed. See [api.syncropic.com](/docs/integrate/api-syncropic) for the per-model price list.

You can move freely between local and hosted using `spl export` / `spl import`: your data is portable by design.

## What you pay for

### Local (free)

You run `spl serve` on hardware you control. Syncropic gets no money, no telemetry, no inspection capability:

- Records, threads, and audit logs live in your instance's record store on your machine
- Federation works peer-to-peer; no Syncropic-operated server in the path
- Provider keys (Anthropic, OpenAI, Google) are yours; you bill those directly
- Updates via `curl https://get.syncropic.com/spl | sh`, a single binary
- Open protocol and open SDKs: the specification is CC-BY-SA-4.0, the SDKs are Apache-2.0, and the runtime is free to download and run

### Hosted ($25 per month per instance, 30-day free trial)

Provision a `<label>.syncropel.app` instance by signing in at [syncropel.com](https://syncropel.com). What's included:

| Included | Notes |
|---|---|
| Hosted instance running `spl serve` | Restarts on crash; updated for you |
| `<label>.syncropel.app` URL with TLS | Certificate managed for you |
| Persistent record store | Your records survive restarts and updates |
| Edge ingress | DDoS protection, geographic edge, HTTP/3 |

Every new instance starts with a 30-day free trial. After the trial, billing is $25 per month for that instance; cancel any time. If you delete an instance, its label returns to the reservation pool after a grace period. Billing questions: your [account portal](https://syncropel.com/account) or support.

### Managed inference (api.syncropic.com)

The [managed inference gateway](/docs/integrate/api-syncropic) is optional and usage-billed at the prices listed on its page. Every call also emits a record on your `th_audit_api_usage` thread, so reconciliation is a record query. You can always bring your own provider keys instead; local and hosted instances both accept them.

## Local and hosted: moving between

`spl export` round-trips your data; both directions take the same path.

### Local to hosted

You've been running `spl serve` on your laptop and want to move to a hosted instance:

```bash
# 1. Export your local instance
spl export --output ~/my-instance.tar.gz

# 2. Provision a hosted instance (gets you a fresh empty <label>.syncropel.app)

# 3. Import your data
SPL_INSTANCE_URL=https://<label>.syncropel.app \
  spl import ~/my-instance.tar.gz
```

Federation pairs need to be re-established post-import (different DID), but records, threads, and audit logs come along intact.

### Hosted to local

You're moving off hosted (sovereignty preference, or you just want it on your own metal):

```bash
# 1. Export your hosted instance
SPL_INSTANCE_URL=https://<label>.syncropel.app \
  spl export --output ~/migrate.tar.gz

# 2. Install spl locally if you haven't
curl https://get.syncropic.com/spl | sh

# 3. Start a local instance and import
spl serve
spl import ~/migrate.tar.gz

# 4. Delete the hosted instance from your account page at your leisure
```

If you delete the hosted instance, its `<label>.syncropel.app` URL returns to the reservation pool after a grace period. Federation peers will need to re-pair against your new local DID.

## Local vs. hosted: which fits

|  | Local (free) | Hosted ($25 per month per instance) |
|---|---|---|
| Cost | Free, plus your hardware | $25 per month per instance after a 30-day trial |
| Ops | Yours (updates, backups, TLS) | Ours |
| Always-on | Only when your machine is on | Yes |
| URL | `localhost:9100` (or however you expose it) | `<label>.syncropel.app` |
| Provider keys | Yours (per-provider billing) | Yours, or via the api.syncropic.com gateway |
| Backups | Manual (your snapshot procedure) | Managed for you |
| Federation | Peer-to-peer | Same; federation is identical between modes |
| Auth | Tokens you mint | Same, plus your syncropel.com identity owns the instance |
| Best for | Sovereignty preference, your own hardware | Zero ops, work from any device |

Start wherever friction is lowest; moving later is one export away.
